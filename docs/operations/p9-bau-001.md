# P9-BAU-001 continuous correctness cadence

The continuous monitor runs tenant-scoped weekly, monthly and quarterly jobs.
Every source audit checks active state, effective expiry and certification age.
An expired or stale source cannot remain answerable: the affected domain is
forced to handoff and the alert is retained with a traceable source/version
reference.

Model, prompt, index and configuration changes require both affected unit-gate
green and recertification evidence before publication. Failed regression or
missing evidence keeps the affected domain in handoff. Rollback restores the
last-known-good source/index/configuration and is idempotent.

This cadence is production-safe by default: it never invents facts, it never
uses model output as KPI/SLO/cost truth, and it never copies secrets or PII into
telemetry. Calendar completion is observed separately from the unit-gated
implementation status.
